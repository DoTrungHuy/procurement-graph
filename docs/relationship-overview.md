# 关系分析页面与数据集总览

结果区按“查询结果标题、紧凑指标、结果分组、网络与图表、明细”展示。网络与排名在桌面并排，对照矩阵场景纵向排列。标题栏的“数据集关系总览”无需执行查询即可打开。

新增只读接口 `GET /api/graph/overview?dataset_id=...`，返回当前数据集完整企业角色名录、有效建模关系与总数。企业总数按名称去重，供应商及采购单位角色分别统计。规则兜底或无有效关系的主体可进入名录，但不为其推断关系。原 `/api/graph` 的默认值和限制保持不变。

总览搜索覆盖完整名录；角色筛选决定搜索主体，关联节点作为上下文保留。画布上限为 80、160 或 300 个节点，统计条明确区分全量总数、匹配数及当前绘制节点和关系数。小数据集在上限以内完整绘制；大数据集先从连接较多的主体展开，可搜索其他企业。画布不会以局部结果冒充全量关系。

后端增加接口后需重启 API。验证使用隔离数据库：后端总览与原五场景测试 6 项通过，生产浏览器 21 项、交互回归 9 项通过；另核对首屏图形位置、总览手机端搜索与空结果恢复。
